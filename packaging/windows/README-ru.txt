PinuiRAG — автономная версия для Windows 10/11 x64

1. Запустите установщик и выберите папку установки.
2. Откройте PinuiRAG через ярлык. Первый запуск подготавливает базы и может занять несколько минут.
3. Интерфейс откроется в обычном браузере. В окне запуска нажмите «Закрыть приложение», чтобы остановить все компоненты.
4. Для ответов и перевода откройте «Настройки GPT-5.4 mini», вставьте свой OpenAI API-ключ и нажмите «Проверить и сохранить».

Python, PostgreSQL, Qdrant, модели поиска, PDF/OCR и документы включены в установщик. Docker и отдельная установка Python не требуются. Поиск на иврите работает без интернета. GPT-5.4 mini требует интернет, собственный API-ключ и оплаченный доступ к OpenAI.

Рабочие данные и настройки сохраняются в %LOCALAPPDATA%\PinuiRAG\data. Ключ OpenAI защищён Windows DPAPI для текущего пользователя. Обновление или удаление установленной программы не удаляет эту папку. Не удаляйте её, если нужны документы и настройки.

Этот персональный комплект содержит текущие документы проекта, включая договоры. API-ключ в установщик не включён.

Актуальность непроверенных источников и полнота законодательного корпуса не подтверждены; источники и статусы видны в приложении.
