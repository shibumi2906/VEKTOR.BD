# PinuiRAG

Приложение для 1–2 пользователей: поиск по Hebrew-документам в Qdrant, ответы на языке обращения и тематическое сравнение двух договоров. PostgreSQL хранит отдельный реестр, исходные блоки, права, поколения индекса и задания. Интерфейс работает через HTTP API.

**Без API-ключа работают:** загрузка PDF/DOCX, OCR, чанки, индексация и поиск на иврите с исходными цитатами. Перевод, связный ответ и тематическое сравнение используют **GPT-5.4 mini** и требуют интернета и собственного OpenAI API-ключа. Проверки общих документов выполнены; приёмка сравнения частных договоров остаётся незавершённой.

## Windows без Python и Docker

Установщик: `dist/PinuiRAG-Setup-Windows-x64.exe`. Он содержит приложение, собственный Python, PostgreSQL, Qdrant, локальные модели, PDF/OCR и подготовленный корпус. При установке дополнительных скачиваний нет. Откройте ярлык PinuiRAG; первый запуск подготавливает базы и открывает браузер.

В боковой панели «Настройки GPT-5.4 mini» введите собственный ключ и нажмите «Проверить и сохранить». Секрет в установщик не включён; сохранённый ключ защищён Windows DPAPI. Рабочие данные находятся в `%LOCALAPPDATA%\PinuiRAG\data`, отдельно от установленной программы. Для завершения нажмите «Закрыть приложение» в окне запуска.

Это персональная сборка с текущими договорами проекта. Установка и автономный поиск проверены на этой Windows с исключёнными системными Python/Docker и заблокированной внешней сетью. Проверка в чистой Windows VM пока не выполнена. Подробности сборки и проверки: [Windows distribution](docs/windows-distribution.md).

## Запуск через Docker для разработки

```powershell
python scripts/init_env.py
docker compose config --quiet
docker compose up --build -d
docker compose ps
```

Используются имеющиеся Docker Desktop и Python; глобальные пакеты Windows не меняются. init_env.py не перезаписывает существующий .env. Модели и индекс уже подготовлены на этом компьютере. Для нового компьютера см. [operations](docs/operations.md).

Интерфейс: http://localhost:8510. API/OpenAPI: http://localhost:8010/docs. Состояние: http://localhost:8010/status. Порты опубликованы только на loopback.

Вход не нужен: интерфейс сразу открывает все документы на личном компьютере. API/UI доступны через localhost. Не публикуйте .env, договоры, data/ и backups.

Для локального поиска выберите «Поиск», иврит, и спросите **מה מטרת תקן 21.1?**. Договоры выбирайте явно; подписание/применимость не подтверждены. Для сравнения выберите 04.2025 и 08.2025 и тему, например парковку. Без темы будет уточнение; с темой и без ключа — LLM_NOT_CONFIGURED.

## Корпус

15 общих PDF (205 страниц): стандарт 21.1, 8 рекомендаций/руководств, 2 подзаконных акта, 2 образца договоров, форма, решение по этике. Также обработаны два локальных договора. Отдельный закрытый проект содержит синтетический OCR fixture. Только стандарт 21.1 подтверждён как действующий; остальные источники не выдаются за актуальные обязательные нормы.

Подтверждённые сводные редакции **16 законов и 2 акта о шамае отсутствуют**. Старые публикации и отдельные поправки удалены по поручению пользователя. Compiler цепочек поправок, даты/переходные условия, provenance и поисковый шлюз реализованы: неполная или просроченная цепочка блокирует нормативный ответ. Рабочие законы не подменены тестовыми данными. См. [corpus-status](docs/corpus-status.md), [legal-currentness](docs/legal-currentness.md).

## Проверки

```powershell
docker compose run --rm --no-deps api uv run --frozen --group dev ruff check app tests scripts ui
docker compose run --rm --no-deps api uv run --frozen --group dev ruff format --check app tests scripts ui
docker compose run --rm --no-deps -e REGISTRY_INTEGRATION=1 api uv run --frozen --group dev pytest -q
python scripts/check_documents.py
docker compose run --rm --no-deps --user root api python -m scripts.accept_local
```

Проверки не вызывают платный API. Приёмка GPT-ответов и переводов, ручная проверка Hebrew и правовая комплектность ещё обязательны. Результаты: [progress](docs/progress.md).

Остановка: docker compose stop; продолжение: docker compose start. Не используйте down -v для обычной остановки. Backup/restore: [operations](docs/operations.md).
