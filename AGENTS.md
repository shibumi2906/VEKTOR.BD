# Работа над PinuiRAG

Источник требований — `docs/specification.md`. Очередность — `docs/implementation-plan.md`; состояние и следующий шаг — `docs/progress.md`; связи требований — `docs/requirements-traceability.md`.

Перед изменением читать текущую задачу, связанные DTO, migrations и tests. При конфликте документов записать конкретный конфликт и продолжать независимые части; пользовательские решения имеют приоритет. Не выполнять следующие этапы как часть текущего без необходимости для его условий готовности.

Не изобретать SDK методы, model IDs, URL и результаты проверок. Версии и зависимости проверять по официальной документации и фиксировать в lock. Не добавлять LangChain/LangGraph без отдельного ADR. Production fake/stub не считать работающим pipeline.

Корпус на иврите. Языки обращения не ограничены русским. Перевод и генерация требуют ключа; запуск и локальный Hebrew search — нет. Сейчас bootstrap инфраструктура и capabilities должны явно показывать незавершённые функции. Только тематическое сравнение; полного сравнения нет.

Реальные договоры, .env, credentials и PII не включать в Git, логи и fixtures. Offline tests не вызывают платные API; live проверки требуют настроенных credentials и бюджетов. Не публиковать и не удалять данные без поручения. Не изменять контейнеры и volumes других проектов.

Использовать существующие инструменты компьютера. Основная среда — имеющийся Docker-образ Python 3.12/uv; локально допускается установленный Python 3.13 (ADR-001). Не устанавливать новый Python без необходимости.

Команды: `python scripts/init_env.py`; `docker compose config --quiet`; `docker compose up --build -d`; `docker compose run --rm --no-deps api uv run --frozen --group dev ruff check .`; аналогично `ruff format --check .` и `pytest -q`.

После изменений запускать проверки текущей задачи и записывать passed/failed/not_run с причинами в progress; обновлять traceability в той же задаче. Состояние готовности подтверждается поведением. Между сессиями продолжать с первого незавершённого пункта progress. Коммит и публикация — только при соответствующем поручении.

Решение пользователя 10.10.2026: личный компьютер, AUTH_MODE=local; UI без администратора, роли и входа. Все локальные документы доступны сразу. Не возвращать обязательные токены в пользовательский сценарий. Loopback и ограничения чужого Host/Origin сохраняются.

Решение пользователя 10.10.2026: поиск по умолчанию во всех доступных документах (all_documents), включая договоры; сохранять тип/статус источников, не выдавать рекомендации или договор за закон. current_norms — отдельное строгое ограничение.
